# Research sources

The following public projects were assessed for architectural patterns:

- NJ MMO: https://github.com/tech-leads-club/nj-mmo
- Orbital Breach: https://github.com/DotanVG/Orbital-Breach
- Aetheria: https://github.com/mositron/Aetheria
- Eidolon: https://github.com/aeml/eidolon

These projects informed separation of client rendering from authoritative simulation, shared gameplay contracts, realtime room/presence patterns, procedural world techniques, persistence, reconnect handling, mobile support and testable phase-based development.
