# v0.4 playtest checklist

## Core
- Start a new character and select a race.
- Move with WASD/arrows and sprint with Shift.
- Attack nearby enemies with Space.
- Interact near NPCs, the ruin and the transfer point with E.

## Progression
- Gain XP from enemies.
- Confirm level-up increases stats and resets HP/ST.
- Open System and inspect stage, attributes, title and authority.

## Consequence
- Trigger the rare decision.
- Verify TAKE and LEAVE open a path.
- Verify DESTROY permanently closes the current route.

## World
- Discover the Transfer Point.
- Travel Aerion -> Velis -> Aerion.
- Confirm world visuals, danger, enemies and weather change.

## Multiplayer
- Open the live site in two browser windows.
- Open Network in each.
- Confirm the shared presence count changes when the second client joins/leaves.

## Safety
- No secrets beyond a publishable Supabase client key are stored in browser code.
- Never copy third-party code or assets into the project merely because a reference repository contains them.
