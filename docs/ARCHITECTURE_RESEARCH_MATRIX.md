# Architecture research matrix

| Reference | Useful pattern | TRANSCENDENCE application |
|---|---|---|
| NJ MMO | Authoritative server, shared game-core, deterministic tests | Server-owned outcomes, shared contracts, seeded simulation target |
| Eidolon | Three.js client + authoritative backend, persistence, reconnect | Browser renderer separated from future simulation and persistence |
| Aetheria | Procedural 3D, mobile, bots, chunked world | Low-bandwidth world generation and mobile-first controls |
| Veilspire | Runtime-generated assets, day/night, weather, map markers | Procedural environment and readable exploration systems |
| Sanctuary's End | Procedural dungeon, loot, skills, co-op | Dungeon, item and progression layers |
| DarkVell | Browser MMORPG + realtime server + PvE/PvP | Social and realtime architecture target |
| SCP3008 | Procedural survival space, day/night aggression | Survival-horror pressure and dynamic danger |
| OpenMMO | Same protocol for agents and human players | Future NPC/agent participation without privileged gameplay rules |

These are design/architecture references. TRANSCENDENCE remains an original project and does not import protected code or assets from these repositories.
