# TRANSCENDENCE

A browser-first vertical slice of the TRANSCENDENCE multiplayer 3D action RPG.

## Vision
A living multiverse where players can begin on different worlds, races, and paths, make consequential choices, progress from mortal toward godhood and beyond, discover unpredictable missions and dungeons, and eventually participate in a persistent multiplayer universe.

## Current milestone
- React + TypeScript client
- Three.js 3D prototype scene
- Player movement and camera
- System status UI
- XP / level foundation
- Mission log and branching choice prototype
- Local persistence
- Responsive HUD and settings foundation

## Architecture
- GitHub: source control
- Supabase: auth, persistent data, realtime backend
- Netlify: web deployment
- Three.js: lightweight browser 3D prototype
- Godot: retained as a future native-client path

The project is developed incrementally with a playable vertical-slice-first strategy. Full multiplayer, combat, AI, dungeons, world simulation, transfer points, higher realms, and the wider multiverse will be implemented in later milestones.
